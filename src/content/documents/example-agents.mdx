## 실무 AGENTS.md 작성 예시

아래 예시는 본 프로젝트에 등록되어 AI 에이전트가 작업 개시 시 가장 먼저 읽는 `AGENTS.md` 실무 헌법 문서 규격입니다.

<MissionBox text="AGENTS.md는 문서 읽기 순서, 권한 범위, 규칙 준수를 강제하는 프로젝트 헌법입니다." />

```markdown
# AGENTS.md

## DOCUMENT_ORDER

1. AGENTS.md
2. .replworks/PRODUCT_SPEC.md
3. .replworks/TECH_STACK.md
4. .replworks/ARCHITECTURE.md
5. .replworks/TASKS.md

## IMPLEMENTATION_RULES

Implement only the selected task.
Do not invent requirements outside PRODUCT_SPEC.md.
Follow TECH_STACK.md and ARCHITECTURE.md strictly.

## TASK_EXECUTION

For every task:

1. Read PRODUCT_SPEC.md, TECH_STACK.md, ARCHITECTURE.md, TASKS.md
2. Implement code & unit tests
3. Run verification commands (Build & Test)
4. Update TASKS.md & Commit
```
