## 실무 PITCHING_SCRIPT.md 작성 예시

아래 예시는 REPL Works의 핵심 피치 메시지를 정리한 `PITCHING_SCRIPT.md` 예시 문서입니다.

<MissionBox text="PITCHING_SCRIPT.md는 제품이 왜 존재해야 하는지 한 문장과 핵심 메시지로 전달합니다." />

```markdown
# PITCHING_SCRIPT.md

## PROJECT DEFINITION
REPL Works는 프로젝트의 의도, 구조, 작업 계획을 Git 문서로 유지하여 
AI 세션이 종료되거나 모델이 바뀌어도 개발을 완수하게 돕는 
문서 주도 AI 개발 프레임워크입니다.

## THE PROBLEM
"프롬프트를 거듭할수록 AI는 앞의 결정을 잊고, 코드는 산으로 갑니다."
AI 세션 중심으로 개발하면 대화가 길어질수록 환각이 발생하고, 
모델이 바뀌면 이전 설계 맥락이 모두 유실됩니다.

## THE CORE MESSAGE
AI can generate code. Projects require structure.
Models change. Projects survive.

## VALUE PROPOSITION
1. Model Independence: 특정 AI 모델에 얽매이지 않고 임의의 에이전트로 교체 가능
2. Project Continuity: 세션 종료 후에도 프로젝트 지식이 코드베이스에 영구 보존
3. Zero Context Waste: 무의미한 이전 대화 기록 대신 검증된 마크다운 문서만 전달
```
