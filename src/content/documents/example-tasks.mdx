## 실무 TASKS.md 작성 예시

아래 예시는 REPL Works 프레임워크의 개발 마일스톤 관리를 위한 `TASKS.md` 문서 작성 구조 예시입니다.

<MissionBox text="TASKS.md는 현재 상태를 나타내며, 미완료된 오직 하나의 TASK만 AI가 실행하도록 제어합니다." />

```markdown
# TASKS.md

## EXECUTION RULES
One Prompt = One Task = One Commit
Do not combine tasks or implement unplanned features.

## PHASE 1: FOUNDATION
- [x] T001 Initialize Astro Project
- [x] T002 Configure Tailwind CSS
- [x] T003 Configure Content Collections

## PHASE 2: PLATFORM FOUNDATION
- [x] T101 Create Site Shell
- [x] T102 Configure Navigation System

## PHASE 3: WEBSITE RELEASE
- [x] T201 Publish Workflow Section
- [x] T202 Publish Prompts Section
- [x] T203 Publish Documents Section
```
