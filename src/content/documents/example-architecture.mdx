## 실무 ARCHITECTURE.md 작성 예시

아래 예시는 본 웹사이트 시스템을 구축하기 위해 실제 작성된 `ARCHITECTURE.md` 청사진 명세입니다.

<MissionBox text="ARCHITECTURE.md는 시스템의 청사진으로서, AI가 임의로 아키텍처를 왜곡하지 못하도록 경계와 패턴을 강제합니다." />

```markdown
# ARCHITECTURE.md

Version 3.0

## PROJECT

REPL Works Website

## PURPOSE

Documentation Platform for REPL Works Framework

## PRIMARY NAVIGATION

Home, Workflow, Prompts, Documents, Tools, Showcase, FAQ

## CONTENT MODEL & ROUTING

- Framework: Astro 6+ (Static Generation)
- Content Source: MDX Collections (`src/content/`)
- Content Routes: `/workflow`, `/prompts`, `/documents`, `/tools`, `/showcase`, `/faq`

## ARCHITECTURAL INVARIANTS

1. Static Export First: 모든 페이지는 GitHub Pages 배포를 위해 완전한 정적 HTML로 컴파일되어야 함
2. Content Independence: 대용량 문서는 컴포넌트 내에 하드코딩하지 않고 MDX 수집함으로 분리
3. No External Server Dependency: 백엔드 서버 DB 없이 완결적인 정적 클라이언트 아키텍처 유지
```
