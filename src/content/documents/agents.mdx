## 2. 개요 및 목적

`AGENTS.md`는 시작 전에 필요한 질문을 하고, 사람의 승인이나 권한이 필요한 지점에서는 멈추면서 `TASKS.md`의 작업을 순서대로 수행하는 자동 실행 지침입니다.

<MissionBox text="How can AI complete the project tasks continuously? (AI가 프로젝트 작업을 끝까지 어떻게 수행할 것인가?)" />

## 3. 사용 방법

가장 편한 방법은 `repl-cli`를 이용하는 것입니다.

### 1. repl-cli 설치

```sh
brew install replworks/tap/repl
```

macOS, Linux, Windows용 사전 빌드 아카이브는 [GitHub Releases](https://github.com/replworks/repl-cli/releases)에서 받을 수 있습니다. Linux에서는 replworks APT 저장소의 `.deb` 패키지도 사용할 수 있습니다.

자세한 내용은 [Tools의 REPL CLI](https://www.repl.net/tools/) 또는 [repl-cli 저장소](https://github.com/replworks/repl-cli)를 참고하세요.

### 2. 문서 생성

프로젝트 루트에서 다음 명령을 실행합니다.

```sh
repl init
```

실행하면 최신 `AGENTS.md`와 함께 `templates/scripts/ask-human.sh`가 설치됩니다. `ask-human.sh`은 AUTO_RUN에 필요한 스크립트입니다.

### 3. 최신 문서로 업데이트

언제든지 다음 명령으로 최신 문서로 업데이트할 수 있습니다.

```sh
repl sync
```

### 4. 실행 정보 준비

문서가 요구하는 계정, 커밋 작성자, 공동 작성자 정보를 시작 프롬프트에 함께 제공합니다. 정보가 없으면 에이전트가 먼저 질문합니다.

### 5. 작업 시작 요청

프로젝트의 AI 에이전트에게 작업을 시작하라고 요청합니다. 에이전트는 권위 문서를 읽고, 필요한 질문을 한 뒤 답변을 받은 다음 `TASKS.md`의 첫 번째 미완료 작업부터 수행합니다.

### 6. 승인 요청 처리

PR 생성, 리뷰, 병합, 권한 부여처럼 사람의 승인이 필요한 단계에서는 에이전트가 멈추고 승인을 요청합니다. 모바일 환경에서도 해당 승인 요청을 확인하고 처리한 뒤 작업을 계속할 수 있습니다.

## 5. 문서 순서 및 자동 실행 범위

`AGENTS.md`는 다음 문서 순서를 따릅니다.

<DocumentFlow
  documents={[
    'AGENTS.md (프로젝트 헌법 & 자동 실행 진입점)',
    '.replworks/PRODUCT_SPEC.md (제품 명세)',
    '.replworks/TECH_STACK.md (기술 구현 규칙)',
    '.replworks/ARCHITECTURE.md (시스템 설계)',
    '.replworks/TASKS.md (순서대로 수행할 작업 목록)',
  ]}
/>

에이전트는 한 번에 하나의 작업을 수행하고 테스트한 뒤, 사람 계정으로 커밋하고 봇 계정으로 PR을 생성합니다. 모든 CI 검사가 통과하면 PR을 병합하고 다음 작업으로 넘어갑니다. 문서 충돌, 확인되지 않은 요구사항, 외부 경계 접근 실패, 테스트 실패, 개발자 결정이 필요한 상황에서는 자동으로 진행하지 않고 사람에게 질문합니다.
