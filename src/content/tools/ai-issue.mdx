## Purpose

`ai-issue`는 대부분의 AI 활용 개발 시 발생하는 **모호한 작업 지시, 불명확한 범위, 완료 기준 부재** 문제를 해결하기 위해 존재합니다.

`ai-issue`는 이슈 생성 시 다음 6개 필수 항목을 강제로 구조화하여 Execution AI가 임의로 추측하는 과업 확장을 차단합니다:

<SpecGrid
  items={[
    '1. Problem Statement (문제 정의)',
    '2. Goal & Target Outcome (달성 목표)',
    '3. Scope & Out-of-Scope (포함 및 제외 범위)',
    '4. Implementation Constraints (구현 제약)',
    '5. Acceptance Criteria (수락 및 검증 기준)',
    '6. Expected Files to Touch (작업 대상 파일)',
  ]}
/>

## Installation

운영체제에 맞는 패키지 매니저로 설치할 수 있습니다:

- **macOS (Homebrew)**: `brew install replworks/tap/ai-issue`
- **Linux (APT)**: `apt install ai-issue`

<Terminal command="ai-issue diagnose" />
