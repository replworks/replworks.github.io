`repl-cli`는 외부 AI 에이전트 실행 과정에서 로컬 프로젝트의 실행 상태와 결과물을 결정론적(Deterministic)으로 관리하는 CLI 도구입니다.

<MissionBox text="Task -> Runtime State -> Validated AI Result (결정론적 런타임 관리)" />

---

## Purpose

AI 실행 과정에서 작업 상태와 결과를 일관되고 가시적으로 관리하기 위해 존재합니다.

<SpecGrid
  items={[
    '1. 프로젝트 실행 환경 초기화 (repl init)',
    '2. 실행 세션 시작 및 상태 체크 (repl runtime start/status)',
    '3. AI 실행 결과물 스키마 및 규칙 자동 검증',
    '4. 로컬 전용 결정론적 런타임 및 로그 기록',
  ]}
/>

## Installation

운영체제에 맞는 공식 포털을 통해 설치합니다:

- **macOS**: `brew install replworks/tap/repl-cli`
- **Linux**: `apt install repl-cli`

<Terminal command="repl --version" />

### 기본 명령어 세트

```bash
repl init            # 프로젝트 초기화
repl runtime start   # 세션 런타임 시작
repl runtime status  # 상태 모니터링
repl runtime stop    # 런타임 정지
```
