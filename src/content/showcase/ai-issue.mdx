## 1. 개요 (Overview)

`ai-issue`는 REPL Works 프레임워크의 첫 번째 호환 CLI 도구입니다. 막연한 대화나 아이디어를 Execution AI가 추측 없이 실행할 수 있는 표준 구조의 GitHub Issue로 자동 작성해 줍니다.

## Workflow Usage

`ai-issue` 도구 개발 시 다음과 같은 REPL Works 워크플로를 적용했습니다:

```text
Discussion AI (이슈 구조화 가이드라인 설계)
       ↓
PRODUCT_SPEC.md & ARCHITECTURE.md (CLI 구조 수립)
       ↓
Execution AI (Homebrew / APT 설치 가능한 CLI 빌드)
       ↓
Human Review (로컬 환경 터미널 검증 및 Release)
```

---

## Tools Used

- **Go / Rust CLI**: 초경량 교차 플랫폼 CLI 바이너리 런타임
- **GitHub CLI (gh)**: GitHub API 이슈 자동 발행 액션
- **REPL Works Issue Template**: 수락 조건 표준 템플릿
