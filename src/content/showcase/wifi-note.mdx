## 1. 개요 (Overview)

WIFI Note는 매장 및 오프라인 공간을 위한 와이파이 접속 안내 및 스마트 고객 경험 개선 서비스를 구축하기 위한 커머셜 프로덕트입니다. 

비공개 상용 웹 애플리케이션 프로젝트이지만, **초기 기획부터 복잡한 비즈니스 규칙 연산 구현까지 REPL Works 프레임워크와 6대 표준 문서 헌법을 완벽히 적용**하여 개발 및 유지보수되고 있습니다.

<MissionBox text="Product Intent Outlives Code: 기능 구현 코드는 지속해서 변경되지만, 왜 이 프로덕트를 만드는가의 의도와 비즈니스 규칙은 Git 문서에 보존됩니다." />

## Workflow Usage

WIFI Note 프로젝트 개발 시 적용된 REPL Works 표준 파이프라인입니다:

1. **의도 정의 및 명세 자산화**: 비즈니스 요구사항을 `PRODUCT_SPEC.md` 및 `ARCHITECTURE.md`에 명시하여 개발 맥락 비용 최적화
2. **1-Task = 1-Commit 실행 파이프라인**: `TASKS.md`에 정의된 개별 태스크 단위로 Execution AI에 프롬프트 전달 및 커밋 생성
3. **세션 독립적 복원**: 새로운 개발 세션 진입 시 대화 이력 없이 Git 문서 자산만으로 100% 동일한 컨텍스트 재구성

```text
Discussion & Spec Definition ──> Git Markdown Memory (.replworks) ──> Task-Based Execution AI ──> Verifiable Release
```

## 6. 프로젝트 가치 및 검증 결과 (What This Project Proves)

WIFI Note는 REPL Works가 단순한 오픈소스 도구 모음이 아니라, **실제 상용 웹 애플리케이션 개발에서 프로젝트 기억을 유지하고 개발 실행 비용을 대폭 절감하는 강력한 방법론**임을 증명합니다.
