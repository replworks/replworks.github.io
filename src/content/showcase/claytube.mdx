## 1. 개요 (Overview)

ClayTube는 장기간에 걸쳐 개발되고 실서비스 환경에서 운영되고 있는 프로덕트입니다.

프로젝트의 주 목적은 기능 개발뿐만 아니라, **시간이 지나도 프로젝트의 초기 의도와 기술 맥락(Project Memory)을 100% 보존할 수 있는 AI 개발 프레임워크를 검증**하는 것입니다.

## Workflow Usage

ClayTube 장기 운영 과정에서 적용된 REPL Works 연속성 워크플로입니다:

1. **지속 가능한 기억 저장소**: 채팅 세션 메모리에 의존하지 않고 모든 기술 변경 사항을 `ARCHITECTURE.md` 및 `TASKS.md`에 기록
2. **세션 복원 절차**: 새로운 개발 회차 진입 시 REPL Works 헌법 문서를 읽어 즉각 컨텍스트 동기화
3. **1-Task = 1-Commit 단위 개발**: 에이전트 작업 실행 시 1개 작업 당 1개의 독립 커밋 작성하여 추적 가능성 극대화

```text
Session Entry ──> Read Git Docs ──> Verify Acceptance Criteria ──> Execute Single Task ──> Git Commit & Push
```

## 6. 프로젝트 가치 및 검증 결과 (What This Project Proves)

ClayTube는 REPL Works가 단기 1회성 프로토타이핑 도구가 아니라, **수개월 이상 유지보수되는 장기 서비스 개발의 연속성을 보장하는 검증된 프레임워크**임을 보여줍니다.
