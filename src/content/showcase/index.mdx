## 1. 개요 및 REPL Works Compatible 정의

REPL Works는 단순한 이론이 아닙니다. 이 페이지는 **REPL Works 방법론과 표준 문서를 실제 프로덕트에 적용하여 프로젝트 지속성과 개발 효율을 증명한 호환(Compatible) 프로젝트 사례**를 소개합니다.

## 2. 공식 호환 프로덕트 (Official Projects)

### 1. REPL Works 공식 웹사이트 (`replworks.github.io`)
본 웹사이트 자체가 REPL Works 방법론과 6대 문서 헌법을 적용해 지속 관리 중인 첫 번째 도그푸딩(Dogfooding) 호환 프로덕션 프로젝트입니다.
- **분류**: Website · Open Source
- **주요 특징**: Astro 6+, Glassmorphic Dark UI, Client-side Search, Site Invariant Test Suite
- [REPL Works 공식 웹사이트 방문](https://www.repl.net)
- [REPL Works 웹사이트 쇼케이스 보기](/showcase/repl-works-website)

### 2. AI Issue Publisher (`ai-issue`)
대화 맥락을 Execution AI가 오버 스코프 없이 실행할 수 있는 GitHub Issue 형태로 자동 변환해 주는 전용 CLI 도구입니다.
- **분류**: Tooling · CLI Tool
- **주요 특징**: Go / Rust CLI, GitHub API 연동, 수락 조건(Acceptance Criteria) 자동 구조화
- [AI Issue Publisher 쇼케이스 보기](/showcase/ai-issue)

### 3. 와이파이 노트 (WIFI Note)
구조화된 프로젝트 기억 자산화를 통해 복잡한 비즈니스 로직을 지속 확장해 나가는 과정을 보여주는 커머셜 웹 애플리케이션 사례입니다.
- **분류**: Commercial · Web App
- **주요 특징**: 비공개 비즈니스 로직, 6대 표준 문서 기반 의도 유지 및 세션 복원
- [WIFI Note 서비스 방문](https://wifinote.net)
- [WIFI Note 쇼케이스 보기](/showcase/wifi-note)

## 4. 사례를 통한 학습 (Learn By Example)

각 쇼케이스 상세 페이지에는 다음 명세 항목이 포함되어 있습니다:

- **1. 개요 (Overview)**: 프로젝트 목적 및 비전
- **2. 사용된 표준 문서 (Documents Used)**: 프로젝트에 적용된 REPL Works 표준 문서 헌법
- **3. Workflow Usage**: Discussion → Document → Execution → Human Review 4단계 워크플로 적용 방식
- **4. Tools Used**: 런타임 기술 스택 및 빌드/배포 도구
- **5. 학습된 레슨 (Lessons Learned)**: 프로젝트 개발 및 운영 과정에서 얻은 핵심 교훈
