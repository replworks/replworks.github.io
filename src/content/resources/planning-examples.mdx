# Planning Examples

## 아이디어 정제 흐름

1. 입력: 광범위한 개념 또는 문제 진술.
2. 출력: 명확해진 아이디어 요약과 이점.
3. 다음 단계: 아이디어를 아키텍처 또는 태스크로 전환.

## 아키텍처 결정 흐름

1. 입력: 프로젝트 목적과 사용자 행동.
2. 출력: 아키텍처 섹션과 제품 경계.
3. 다음 단계: ARCHITECTURE.md를 게시하고 콘텐츠 컬렉션을 정렬.

## 태스크 분해 흐름

1. 입력: 정의된 프로젝트 목표.
2. 출력: 완료 규칙이 있는 순서화된 태스크.
3. 다음 단계: 다음 태스크를 실행하고 태스크를 세분화.

이 분리는 계획과 구현을 명확하게 구분합니다.
