# Resources

REPL Works Resources 섹션은 프로젝트 기억을 지원하는 실용 자료를 정리합니다.

- **Templates** — 일관된 프로젝트 문서를 위한 재사용 가능한 템플릿.
- **Example Documents** — REPL Works에 맞춘 실제 문서 예시.
- **Long Context Examples** — 세션 복구를 위한 문맥 요약 예시.
- **Repository Examples** — Git 중심 리포지토리 구조 예시.
- **Planning Examples** — 전략과 실행을 분리하는 계획 문서 예시.
- **FAQ** — REPL Works 핵심 개념에 대한 간결한 답변.
