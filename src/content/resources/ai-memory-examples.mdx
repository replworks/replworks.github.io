AI_MEMORY.md는 채팅 기록이 아니다.

AI_MEMORY.md는 세션 복구를 위한 기억 압축본이다.

목적은 과거를 보존하는 것이 아니라 미래의 AI가 빠르게 맥락을 복원할 수 있도록 하는 것이다.

---

## What Should Be Included

AI_MEMORY에는 다음 내용을 남긴다.

```text
프로젝트 현재 상태

중요한 의사결정

선택한 방향

포기한 방향

현재 고민

다음 논의 주제
```

---

## What Should Not Be Included

다음 내용은 포함하지 않는다.

```text
전체 채팅 기록

모든 프롬프트

모든 실험 과정

사소한 구현 세부사항

이미 ARCHITECTURE.md에 존재하는 내용
```

## Next Topics

## Large Project Example

```markdown
# AI_MEMORY.md

## Project Status

Version 2 개발 중

---

## Architecture Direction

- Monolith 유지
- Event Sourcing 도입 안 함

---

## Major Decisions

- OpenAI 의존 제거
- Multi-Model 지원

---

## Lessons Learned

- Agent Framework보다 Memory 구조가 중요함
- Prompt 최적화보다 Architecture 정리가 효과적이었음

---

## Current Risks

- 운영 비용 증가
- 사용자 온보딩 복잡성

---

## Next Discussions

- Plugin System
- Enterprise Plan
- Self-Hosting
```

---

## Core Principle

AI_MEMORY는 프로젝트 문서가 아니다.

AI_MEMORY는 세션 복구 문서다.

Project Memory는 Repository에 존재한다.

AI_MEMORY는 그 기억에 빠르게 도달하기 위한 부트스트랩이다.

---

Models forget.

Projects must not.
