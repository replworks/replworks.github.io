# Repository Examples

## 최소 구성 리포지토리

```text
src/
  content/
  layouts/
  pages/
  lib/
package.json
astro.config.mjs
TASKS.md
ARCHITECTURE.md
```

## 전체 프로덕션 리포지토리

```text
src/
  assets/
  components/
  content/
    manifesto/
    specification/
    workflow/
    resources/
    showcase/
  layouts/
  pages/
  styles/
package.json
tsconfig.json
astro.config.mjs
README.md
TASKS.md
ARCHITECTURE.md
```

## 다중 서비스 리포지토리 (개념적)

```text
services/
  web/
    src/
    package.json
    TASKS.md
    ARCHITECTURE.md
  docs/
    src/
    package.json
    ARCHITECTURE.md
packages/
  ui/
  shared/
README.md
TASKS.md
ARCHITECTURE.md
```

이 구조는 Git-first 프로젝트 기억 아래에서 문서와 코드를 정렬합니다.
